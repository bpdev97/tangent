  sidebar chrome renders `APP_BASE_NAME`, and upstream's Usage navigation is additive to Tangent's
  Automations entry.

  sidebar implementations keep generic chats pathless, omit project actions, and use chat icons.

  upstream background-liveness reaper fix applies without a Hermes-specific branch. Usage remains
  unsupported until upstream defines an extensible or Hermes-capable transcript contract.
- `FORK-PUSH-001`: Personal relay settings, authorization, HTTP routing, RPC testing, and the second
  awareness sink remain intact across the upstream settings and server additions.
- `FORK-IMAGE-001`, `FORK-CODEX-001`, and `FORK-PALETTE-001`: The upstream range does not touch or
  supersede their behavior.

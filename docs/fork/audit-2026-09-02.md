# Tangent upstream sync audit: 2026-09-02

## Result

This sync merges `upstream/main` at `28ddaf759` into Tangent `main`. The range contains 171 upstream
commits after the previous `c0e09f323` baseline and advances the server package from 0.0.36 to
0.0.38. It includes the upstream 0.0.37 and 0.0.38 releases plus subsequent fixes through the
selected main commit.

The merge follows upstream wherever Tangent has no documented exception. It adopts upstream's
sticky new-thread model-selection fix, server-owned settling and shared settings, streaming and
replay performance work, desktop remote updates and restart continuation, expanded media and voice
support, assistant citations, source-control improvements, and connection hardening. Every
registered fork feature remains active.

## Upstream changes adopted

- new-thread model choices remain sticky across drafts and environments, provider options no longer
  materialize implicit catalog defaults, and automatically seeded project model defaults are
  removed while explicit project defaults remain intact;
- thread settling now belongs to the server, shared preferences synchronize across environments,
  and active threads can continue across server restarts;
- orchestration replay, streaming projections, tool updates, transcript scans, provider-session
  lookups, sidebar activity, and server-config bootstrap traffic are bounded or incremental;
- desktop can update a remote Mac from the Update action, prevents accidental service downgrades,
  handles activation from the CLI, improves quit confirmation, and restores preview recording and
  rendering after the Electron 43 upgrade;
- mobile gains offline voice input, file sharing and receiving, native image/PDF/video presentation,
  composer-time attachment upload, thread-reference copying, updated chat transitions, and a newer
  vendored GhosttyKit;
- web and mobile render Codex citations and artifact templates, while web adds richer file viewing,
  pull-request filters and actions, settings search, source-control fixes, and safer browser-close
  confirmation; and
- provider integrations gain remote Claude model discovery, project-skill discovery, bounded probes,
  Grok model and lifecycle fixes, and OpenCode child-session cleanup.

## Fork compatibility decisions

- `FORK-DIST-001` keeps Tangent names, bundle IDs, URL schemes, state roots, personal release tags,
  verified `tangent-server` artifacts, and personal release workflows. Upstream remote desktop
  updates, restart continuation, downgrade protection, packaging checks, and Electron changes are
  adopted around that identity.
- `FORK-CHAT-001` keeps managed generic chats, preferred hosts, the generic sidebar and palette
  actions, the iOS composer, and macOS Quick Chat. Generic-chat projects no longer write an
  automatic Codex model seed, so their drafts participate in upstream's sticky model selection just
  like repository-backed projects.
- `FORK-HERMES-001` keeps its supervised TUI-gateway transport, profiles, automations, and workspace
  snapshot refresh. Upstream claimed migration ID 44 for automatic model-default cleanup, so the
  Tangent compatibility migration moves to ID 45 and reruns cleanup idempotently for installations
  whose existing ledger already recorded Tangent's former ID 44.
- `FORK-PUSH-001` keeps the Tangent APNs identity, per-environment registration, global personal
  registration, and relay behavior through the new mobile bootstrap and shared-settings layers.
- `FORK-IMAGE-001` keeps shared HEIC/HEIF-to-JPEG normalization and extends it through upstream's
  file, video, native-preview, and composer-time upload flows.
- `FORK-PALETTE-001` keeps Control-N and Control-P navigation while adopting upstream thread-reference
  copying and the latest command actions.
- `FORK-LINEAR-001` stays registered in server startup and desktop/web preview destinations while
  adopting upstream preview lifecycle and browser-close changes.
- `FORK-MERMAID-001` remains layered into the shared Markdown rendering path alongside upstream
  citations, artifact templates, media links, and file previews.
- `FORK-PREVIEW-001` keeps per-thread mount ownership and server-settled teardown. Upstream's
  server-owned automatic settling now supplies the authoritative signal; missing or client-derived
  state still fails open.

## Migration compatibility

Tangent 0.1.47 shipped `044_TangentMigrationCompatibility`, while upstream later assigned ID 44 to
`ClearAutomaticProjectModelDefaults`. Reusing either meaning would make one side invisible to
existing ledgers. The merged manifest therefore preserves upstream ID 44 and registers
`TangentMigrationCompatibility` as ID 45. Migration 45 first executes upstream's cleanup
idempotently, then repairs the Tangent compatibility state. Tests cover both a new database and a
legacy Tangent ledger that already contains the former ID 44 row.

# Tangent upstream sync audit: 2026-08-10

## Result

This sync merges `upstream/main` at `a7b0366cb` into Tangent tip `fb4dd59a1`. The range contains 55
upstream commits after the previous `89ee692bf` baseline and advances the upstream server version
from `0.0.32` to `0.0.33`. Tangent keeps every active feature registered in
[`FORK.md`](../../FORK.md), while adopting upstream's new pull-request experience, project settings,
mobile usage view, provider lifecycle fixes, and performance and security improvements.

No incoming change fully replaces an active Tangent feature. Upstream still has no managed generic
chat environment, Hermes TUI-gateway provider, personal push relay, shared HEIC normalization,
tagged Codex MCP approval flow, Control-N/Control-P palette navigation, Linear destination resolver,
secure streaming-aware Mermaid rendering, or settled-preview suspension policy.

## Fork compatibility decisions

- `FORK-DIST-001`: preserved `downstream/config.ts`, `downstream/mobile-config.ts`, Tangent state,
  release/service/update identifiers, personal workflows, and the fork-owned server dependencies.
  Upstream's `0.0.33` package baseline and release workflow improvements are otherwise retained.
- `FORK-CHAT-001`: composed upstream's asynchronous per-project environment-mode resolver with the
  generic-chat override. Generic drafts never consult project defaults, always stay local, and keep
  `approval-required`; normal drafts follow upstream precedence and race handling. Upstream favicons
  apply only to normal projects.
- `FORK-HERMES-001`: retained additive provider, automation, settings, RPC, and server layers. The
  compatibility migration moved from 39 to 41 without changing its idempotent repair behavior.
- `FORK-PUSH-001`: retained the second awareness sink, redacted server settings, authenticated
  routes, mobile reconciliation, and relay package unchanged.
- `FORK-IMAGE-001`: retained server-side HEIC dependencies and normalization before upstream's new
  provider image-reading path.
- `FORK-CODEX-001`: retained tagged MCP elicitation handling and conditional session persistence;
  upstream's queued-follow-up stop fix composes with it.
- `FORK-PALETTE-001`: retained Control-N/Control-P navigation while accepting the surrounding
  command-palette favicon and settings changes.
- `FORK-LINEAR-001`: kept server-secure Linear resolution and dedicated browser tabs, but reduced
  divergence by routing GitHub choices through upstream's in-app pull-request viewer. Linear and
  upstream pull-request services are both server-lifetime dependencies, and their right-panel
  surfaces coexist in one store.
- `FORK-MERMAID-001`: retained the completed-fence rendering seam while accepting upstream's
  Markdown alerts and review rendering changes.
- `FORK-PREVIEW-001`: retained renderer-wide settled-thread suspension across the expanded upstream
  set of browser and pull-request surfaces.

## Conflict resolution

The merge produced 14 conflicts in expected shared touchpoints. Resolutions composed rather than
replaced behavior:

- generic-chat glyphs and capability guards gained upstream project favicon data;
- generic draft creation retained its forced runtime/workspace policy inside upstream's async
  project-default and concurrent-draft handling;
- both Tangent identity and upstream OOM-policy boot tests remain;
- upstream migration IDs 39/40 remain canonical and Tangent compatibility advances to 41;
- Linear and pull-request server layers and right-panel surfaces remain registered together;
- the default and legacy sidebars retain Chats and Linear behavior while adopting project routes,
  Pull Requests, Usage, drafts, and favicons;
- upstream PR/agent tabs and status counts coexist with Tangent project-tool restrictions; and
- Tangent Automations remains beside upstream Pull Requests, Usage, and Settings.

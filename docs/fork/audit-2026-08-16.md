# Tangent upstream sync audit: 2026-08-16

## Result

This sync merges `upstream/main` at `bab4b6f02` into Tangent tip `b483dd6cb`. The range contains 196
upstream commits after the previous `a7b0366cb` baseline. The upstream server package remains at
`0.0.33`. Tangent keeps every active feature registered in [`FORK.md`](../../FORK.md), while
adopting upstream's mobile task composer and native settings navigation, built-in themes, pull
request improvements, Windows desktop server sidecar, prompt stashing, and provider/server
reliability fixes.

No incoming change fully replaces an active Tangent feature. Upstream still has no managed generic
chat environment, Hermes TUI-gateway provider, personal push relay, shared HEIC normalization,
tagged Codex MCP approval flow, Control-N/Control-P palette navigation, Linear destination resolver,
secure streaming-aware Mermaid rendering, or settled-preview suspension policy.

# Tangent upstream sync audit: 2026-08-26

## Result

This sync merges `upstream/main` at `a3a8cbd60` into Tangent tip `c69e3fe55`. The range contains 91
upstream commits after the previous `592c5983c` baseline and advances the server package from
0.0.33 to 0.0.34.

The merge adopts upstream implementations and UI structure wherever possible. `FORK-CODEX-001`
is retired because upstream now carries the complete Codex MCP elicitation, persistence-choice,
activity, and web/mobile approval flow. Every other registered fork feature remains active.

## Upstream changes adopted

- pre-uploaded web attachments, including client-side HEIC-to-JPEG conversion and draft cleanup;
- Codex app-access elicitation prompts with explicit per-request approval choices;
- durable thread-to-pull-request links and linked-PR status resolution;
- thread settlement shortcuts and ordering fixes;
- client-origin and mobile-device connection metadata;
- Claude auto-compaction configuration and provider/model compatibility improvements;
- semver-aware client/server skew detection;
- macOS launch-agent PATH restoration and remote SSH PATH fixes;
- attachment, Markdown image, browser, sidebar, and composer reliability/performance fixes; and
- upstream server release 0.0.34 and migrations 41 through 43.

## Fork reduction and compatibility decisions

- Removed Tangent's Codex MCP approval parser, request kind, tests, and maintenance record. Upstream
  owns this flow end to end. Hermes maps upstream's new `acceptAlways` decision to session scope so
  the shared contract cannot widen Hermes permissions.
- Adopted upstream's web HEIC conversion and upload queue. `FORK-IMAGE-001` remains only as the
  server compatibility boundary for inline attachments from mobile and older clients.
- Moved Tangent's idempotent compatibility migration from 41 to 44. Migration 44 repairs the
  upstream migration-41 auth-session columns on databases that already recorded Tangent's former
  migration 41, then preserves the existing Hermes and projection repairs.
- Combined Tangent's identity-aware launchd label and pinned release source with upstream's
  environment-PATH capture.
- Hardened upstream's legacy-Node entrypoint fallback by canonicalizing both sides of the path
  comparison. This preserves npm/npx symlink detection on macOS, where `/var` and `/private/var`
  can name the same file.
- Linear consumes upstream's linked pull-request result as the authoritative PR URL while retaining
  lazy, server-owned destination resolution.
- Generic-chat entry points retain Tangent host selection and projectless behavior while adopting
  upstream's Android header, tablet layout, upload, composer, and settings structures.

## Explicit downstream decisions retained

- `FORK-DIST-001`: Tangent keeps separate state, service identity, verified GitHub Release runtime,
  desktop artifacts, and personal mobile channel.
- `FORK-CHAT-001`: managed generic chats and Quick Chat remain because upstream has no equivalent
  projectless chat or strict host-selection policy.
- `FORK-HERMES-001`, `FORK-PUSH-001`, `FORK-LINEAR-001`, `FORK-MERMAID-001`,
  `FORK-PREVIEW-001`, and `FORK-PALETTE-001` remain under their recorded constraints.
- `FORK-IMAGE-001` remains for mobile and older inline clients; upstream's current implementation is
  web-only.

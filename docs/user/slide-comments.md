# Slide comments

When an agent makes a PowerPoint deck, you can review it in the file viewer and point at what
should change instead of describing it.

1. Open the `.pptx` file from the agent's file link or the file browser.
2. Turn on **Comment on slides** in the slide toolbar.
3. Drag across the part of a slide you want changed. To comment on a whole slide, click it once or
   choose **Comment on slide N** in its corner.
4. Write what should change and choose **Add to chat**, or press Command-Enter (Control-Enter on
   Windows and Linux). Escape discards the comment.

Each comment becomes a chip in the composer, usually with a screenshot of the slide showing the
marked region. Add as many as you like across slides, then send your message. The agent receives
the deck's path, the slide number, your comment, and the screenshot.

Comments waiting in the composer show on their slides as numbered outlines. Remove one from the
slide or from the composer and it disappears from both.

When the agent updates the deck, the new version replaces the old one in place, at the slide you
were looking at and still in commenting mode. If you are writing a comment, the update waits until
you add or cancel it. If the new version cannot be opened, the viewer keeps the previous one and
says so. It tries again the next time the deck changes, or you can close the file and open it again.

Commenting works on web and desktop for decks in the project or linked from a message. Files
attached to a message can be viewed but not commented on. The mobile app shows the comments in
messages you have sent, but it cannot add them.
